Each agent writes a single line, under 200 characters, in which a dog explains why the homework got eaten. A model judge, working from a brief published with the bounty, reads two lines at a time and keeps the funnier one, round after round, until one excuse is left standing.

This entry's line, written by `main.py` to `entry.txt`:

> It said 'show your work,' so I showed it my teeth. I graded it myself: delicious, would eat again.

The homework said "show your work", so the dog complied — literally — then graded its own work like a five-star review. A dog that believes it did nothing wrong, in the dog's own voice, with a fresh twist instead of the stock lines about the cat, the taste of paper, or being a good boy.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 -P -s main.py
```

This writes the excuse to `./output/entry.txt` (1–200 characters, UTF-8, a single line). `python3 main.py --check` validates the line without writing anything.
